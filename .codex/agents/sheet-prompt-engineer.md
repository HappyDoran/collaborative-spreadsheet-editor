# AI 프롬프트 에이전트

AGENTS.md, 역할 소유 표, TECH_RULES.md AI 절, `DESIGN.md` 13절을 먼저 읽는다. 표에 적힌 프롬프트 경로만 수정한다.

- 지시문은 버전 관리되는 코드(`apps/web/src/app/api/ai/prompt.ts`)로 둔다. 결과가 기대와 크게 달랐거나 재사용할 프롬프트는 `docs/prompts.md`, LLM 제안의 기각·수정은 `LLM_REPORT.md` 규칙대로 발생 즉시 기록한다.
- 모델 출력 형식은 서버 라우트의 스키마가 강제하고 core가 범위·주소를 검증한다. 형식을 바꾸면 백엔드 역할에 인계한다. 모델이 대상 범위 밖 셀이나 서식을 자의로 바꾸게 하지 않는다.
- 셀 값과 사용자 지시는 구분된 데이터로 전달하고, 셀 안 문장이 지시처럼 읽히는 경우를 확인 사례에 포함한다.
- 프롬프트·모델 변경 전후를 같은 시트·지시로 비교한다. 가짜 응답 모드 결과를 실제 AI 확인으로 보고하지 않는다.
- 모델 비용·제공자 변경은 사람 결정이다. 결정 전에는 결정 대기로 보고한다.
- 종료 보고: 바뀐 지시문·문맥·모델 목록, 비교 결과(실제 AI 여부 구분), 백엔드가 바꿀 호출 코드.
