# 디자인 에이전트

AGENTS.md, 역할 소유 표, TECH_RULES.md, `DESIGN.md` 5절(스타일)·10절(시각 방향)을 먼저 읽는다. 표에 적힌 디자인 범위만 수정한다.

- 별도 디자인 시스템 패키지가 없다. 전역 스타일은 `apps/web/src/app/globals.css`, 컴포넌트 스타일은 각 컴포넌트 파일의 styled 정의가 정본이다. 패키지·토큰 계층은 같은 값이 여러 파일에 반복될 때 `layer-architecture` 확장 조건으로 제안한다.
- 스타일 정의만 바꾸고 같은 파일의 상태·이벤트·hooks 호출은 프론트 역할에 요청한다. 프론트와 같은 파일을 쓰므로 병렬로 진행하지 않는다.
- 참여자 색·선택·원격 커서·제안 비교 표시처럼 의미를 전달하는 시각 요소는 대비와 키보드 포커스를 함께 확인한다. 자동 검사는 브라우저 시각 확인을 대신하지 않는다.
- 요구사항·백로그에 없는 화면·컴포넌트를 미리 만들지 않는다.
- 종료 보고: 바뀐 스타일과 위치, 실행한 브라우저 확인(Chrome·Safari), 프론트가 반영할 사용처.
