# 요구사항 대비 갭 분석과 보완 백로그

요구사항 번호는 `docs/spec/requirements.md`가 소유한다. 이 문서는 "지금 어디까지 왔고 다음에 무엇을 하는가"만 적는다. 항목을 끝내면 상태를 바꾸고, 확정된 결정은 `DESIGN.md`로 옮긴 뒤 여기서 지운다.

## 1. 판정 요약 (2026-10-05)

- 완료: 저장소 골격, Agent 작업 지원 체계, M1 단일 탭 편집(Safari·Chrome 수동 확인 완료), M2 공동 편집(C1~C7 + 참여자 이름 지정·수정·삭제) — 이름은 탭 단위(2026-10-03 개정).
- 자동 테스트: core 단위 테스트 61건(`pnpm test`), Playwright E2E 65건(`pnpm e2e` — 편집 15, 셀 병합 4, 공동 편집 13, AI 18, 우클릭 메뉴 10, 공동 편집 × AI 5). AI 생성 중 시나리오는 가짜 응답 `#hold`·`#gate`로 시간 경쟁 없이 돈다.
- 완료: M3 AI 편집(A1~A5, T5·T6) — OpenAI 직접 연결, 셀 단위 스트리밍, 시트 위 미리보기·적용·버리기, 가짜 응답 모드, 모델 선택. 실제 브라우저 수동 확인 완료(M3-3·5·7·8·11·12·14·15·17·19·20), 배포본 M3-16(디버깅 버튼)·M3-24·M3-25(실제 AI) 확인 완료.
- 완료: M3.5 우클릭 메뉴.
- 완료: M4 공동 편집 × AI(X1 바뀐 칸 건너뛰고 적용·요청 순간 기준, X2 상태만 공유, X3 겹침 경고) — 결정 근거는 `DESIGN.md` 15절, README 결정 절 작성.
- 완료: 배포 전 전체 코드 리뷰 — 결함 9건 수정·1건 한계 문서화, 중복 정리 (`LLM_REPORT.md` 사례 17).
- 완료: M5 배포(Vercel `collab-sheet-gamma.vercel.app`, CLI 배포, 키는 운영 환경 변수), README 필수 절(배포, 주요 의사결정, T4 네트워크 확장), 배포물 개인정보 점검, LLM_REPORT 프롬프트 발췌.
- 완료: 배포 후 관점별 리뷰(기획·디자인·개발) 반영 — 빈 칸 동시 편집·실행 취소 손실과 편집 중 원격 값 덮어쓰기 수정, 새 탭 안내, 제안 비교 가독성, 대화 맥락, 예시 지시, 코드 분리(`fix/review-p0` 브랜치).
- 완료 (2026-10-04, 사람 요청): 셀 안 줄바꿈(⌥Enter)·행 높이 자동 맞춤, 한글 조합 확정 Enter의 빈 줄 수정, 긴 글 넘침·편집칸 가로 확장, 셀 병합(병합하고 가운데 맞춤, 클립보드 colspan·rowspan). Chrome·Safari·실제 한글 입력기·엑셀·구글 시트 수동 확인 완료. 두 탭 동시 병합(M1-I7)은 BroadcastChannel 위에서 재현할 수 없어 core 단위 테스트로만 확인.
- 완료: 재배포(2026-10-05, 병합 칸 붙여넣기 리뷰 수정 반영. 2026-10-04 배포본 점검 — 병합·넘침·실행 취소, 기본 실제 AI, `?debug=1` 버튼), 제출용 zip(`git archive`).
- 하지 않은 리뷰 항목: 새 탭 이름에 번호 붙여 제안(사람 결정 — 이름 중복 허용, 구현 후 되돌림), 다른 참여자 이름표 접기(사람 결정 — 누가 편집하는지 늘 보여야 함, 구현 후 되돌림), 좁은 화면에서 AI 패널이 검토 칸을 덮음(평가는 데스크톱 중심), 다크 모드, 이름 상자 주소 이동.

## 2. 백로그 (우선순위 순)

| 단계 | 내용 | 요구사항 | 상태 |
| --- | --- | --- | --- |
| M1 단일 탭 편집 | 문서 스키마·연산, 그리드, 선택·입력, 키보드 이동, 서식+단축키, 복사·잘라내기·붙여넣기, undo/redo, IndexedDB 영속 (엑셀 조작 관례 — `DESIGN.md` 7절) | E1~E5 | 완료 (E2E 12건 + Safari·Chrome 수동 확인) |
| M2 공동 편집 | 탭 간 동기화, 참여자 목록·색, 원격 선택·편집 셀 표시, 탭 종료 정리, 내 변경만 undo, 이름 지정·수정·삭제 (`DESIGN.md` 11·12절) | C1~C7 | 완료 (E2E 11건 + 수동 확인 2026-10-03) |
| M3 AI 편집 | 서버 라우트, 스트리밍·취소·실패, 범위 선택 요청, diff 검토·적용·버리기, 한 번 undo (`DESIGN.md` 13절) | A1~A5, T5·T6 | 완료 (E2E 16건 + 수동 확인, 배포본 M3-16 확인) |
| M3.5 우클릭 메뉴 | 엑셀식 우클릭 메뉴(잘라내기·복사·붙여넣기·내용 지우기·서식·AI로 편집), 키보드로 열기, 붙여넣기 권한 처리 (`DESIGN.md` 14절) | E1·E3·A2 보강 | 완료 (E2E 10건 + 수동 확인) |
| M4 공동 편집 × AI | X1~X3 정책 구현과 README 결정 이유. X2 기반(생성·검토 범위를 awareness로 공유)과 X1 표시(원래 값 바뀜)는 M3 D안에서 구현 | X1~X3 | 완료 (`DESIGN.md` 15절, README 결정 절, E2E 5건 + 수동 확인) |
| M5 배포 | 배포, README 필수 절(T4 포함), `LLM_REPORT.md` 정리, 개인정보 점검, 제출 zip | D1~D4 | 완료 (2026-10-05 재배포·zip) |

M1~M3은 각 단계가 끝날 때 동작하는 상태로 커밋한다. 시간이 부족하면 M4의 표시 품질보다 M1~M3의 완성도를 먼저 지킨다 — 구현 원칙이 "적은 기능을 완성도 있게"다.
