# 수동 확인 시나리오

사람이 브라우저에서 직접 확인하는 절차의 정본이다. 결과(브라우저 × 날짜 × 통과 여부)는 `README.md` 수동 매트릭스에 시나리오 ID로 기록한다. ID는 `단계-영역번호`(예: `M1-D3`) — 요구사항 번호(`docs/spec/requirements.md`의 E·C·A)와 구분하려고 단계 접두를 붙인다. 기능이 바뀌면 같은 커밋에서 이 문서를 갱신한다. 검증 계층에서의 위치는 `.codex/skills/test-policy/SKILL.md`.

- **자동**: Chromium Playwright 스크립트로 이미 돌린 항목. 사람은 Safari와 실제 입력기에서만 다시 본다.
- **수동 전용**: 자동화로 재현할 수 없거나(실제 IME, 외부 앱 클립보드) 사람의 판단이 필요한(보기·느낌) 항목.
- 단축키는 Mac 기준(⌘)이다. Windows·Linux에서는 Ctrl로 같은 결과가 나와야 한다.

## 공통 준비

1. `pnpm dev` 실행 후 `http://localhost:3000`을 연다. 배포본을 확인할 때는 배포 주소를 연다.
2. 깨끗한 상태에서 시작하려면 시트 전체를 선택(⌘A)하고 Delete를 누른다. 저장소까지 비우려면 개발자 도구 → Application → IndexedDB → `sheet:default`를 삭제하고 새로고침한다.
3. 각 시나리오는 앞 시나리오와 독립이다. 필요한 값은 시나리오 안에서 만든다.

## M1-A 입력과 이동

| ID | 단계 | 기대 결과 | 구분 |
| --- | --- | --- | --- |
| M1-A1 | A1 셀 클릭 → `hello` 입력 → Enter | A1에 `hello`, 선택은 A2. 상태 표시줄이 입력 중 "입력", 확정 후 "준비" | 자동 |
| M1-A2 | A1 클릭 → `10` Tab `20` Tab `30` Enter | A1·B1·C1에 값, 선택은 A2 (Tab으로 출발한 A열로 복귀) | 자동 |
| M1-A3 | Shift+Enter, Shift+Tab | 각각 위, 왼쪽으로 이동. 시트 끝(A1의 위·왼쪽)에서는 움직이지 않는다 | 수동 전용 |
| M1-A4 | 값이 있는 셀 선택 → F2 → `!` 입력 → Enter | 기존 값 뒤에 `!`가 붙는다 | 자동 |
| M1-A5 | 값이 있는 셀 더블클릭 → 글자 사이를 클릭 → 입력 | 클릭한 위치에 커서가 놓이고 그 자리에 입력된다 | 수동 전용 |
| M1-A6 | 값이 있는 셀 선택 → 바로 `bye` 입력 → Esc | 원래 값 그대로, 상태 표시줄 "준비" | 자동 |
| M1-A7 | 입력 모드(바로 타이핑)에서 → 방향키 | 값이 확정되고 오른쪽 셀로 이동 | 수동 전용 |
| M1-A8 | 편집 모드(F2)에서 ← → 방향키 | 셀 이동 없이 글자 사이 커서만 움직인다 | 수동 전용 |
| M1-A9 | 값이 있는 셀 → Backspace → `new` → Enter | 기존 값이 지워지고 `new`로 바뀐다 | 수동 전용 |
| M1-A10 | `1,234`, `-5.5`, `12%`, `abc` 입력 | 앞의 세 값은 오른쪽 정렬, `abc`는 왼쪽 정렬 | 자동(일부) |
| M1-A11 | 값 편집줄(이름 상자 오른쪽 입력칸) 클릭 → 값 수정 → Enter | 셀 값이 바뀌고 선택이 아래로 이동, 포커스가 그리드로 돌아온다 | 수동 전용 |
| M1-A12 | 값 편집줄에서 수정 중 Esc | 원래 값 유지, 포커스가 그리드로 돌아온다 | 수동 전용 |
| M1-A13 | 방향키를 계속 눌러 Z열·100행까지 이동 | 화면이 따라 스크롤되고, 선택 셀이 고정 머리글 아래로 숨지 않는다 | 수동 전용 |

## M1-B 선택

| ID | 단계 | 기대 결과 | 구분 |
| --- | --- | --- | --- |
| M1-B1 | A2 클릭 → Shift+→ → Shift+↓ | 이름 상자 `A2:B3`, 범위는 옅은 군청 배경, 시작 셀(A2)은 굵은 테두리 | 자동(일부) |
| M1-B2 | A3에서 C5까지 드래그 | 이름 상자 `A3:C5`, 해당 행·열 머리글이 강조된다 | 자동 |
| M1-B3 | A1 클릭 → C3 Shift+클릭 | `A1:C3` 선택 | 수동 전용 |
| M1-B4 | 열 머리글 `C` 클릭 / 행 번호 `5` 클릭 | C열 전체 / 5행 전체 선택 | 수동 전용 |
| M1-B5 | 왼쪽 위 모서리 칸 클릭, 또는 ⌘A | 시트 전체 선택 | 수동 전용 |
| M1-B6 | 숫자 셀 두 개 이상 포함한 범위 선택 | 상태 표시줄에 합계·평균·개수 | 자동 |

## M1-C 서식

| ID | 단계 | 기대 결과 | 구분 |
| --- | --- | --- | --- |
| M1-C1 | 셀 선택 → ⌘B, ⌘I, ⌘U | 굵게·기울임·밑줄이 켜지고, 툴바 버튼이 눌린 상태로 바뀐다 | 자동(굵게) |
| M1-C2 | 같은 셀에서 ⌘B 한 번 더 | 굵게가 꺼진다 | 수동 전용 |
| M1-C3 | 범위 중 일부만 굵게인 상태에서 범위 선택 → ⌘B | 범위 전체가 굵게 (전부 켜져 있을 때만 끈다) | 단위 테스트 |
| M1-C4 | 툴바 B·I·U 버튼 클릭 | 단축키와 같은 결과, 클릭 후에도 바로 타이핑하면 셀에 입력된다(포커스 유지) | 수동 전용 |
| M1-C5 | 굵게인 셀에서 Delete | 값만 지워지고, 새로 입력하면 굵게로 보인다 | 단위 테스트 + 수동 |

## M1-D 복사·잘라내기·붙여넣기

| ID | 단계 | 기대 결과 | 구분 |
| --- | --- | --- | --- |
| M1-D1 | 값·굵게가 있는 A2:B2 선택 → ⌘C → D5 클릭 → ⌘V | D5:E5에 값과 굵게, 붙여넣은 범위가 선택된다 | 자동 |
| M1-D2 | ⌘C 직후 | 복사한 범위에 점선 테두리. Esc 또는 입력 시작 시 사라진다 | 수동 전용 |
| M1-D3 | 셀 하나 ⌘C → 2×2 범위 선택 → ⌘V | 네 칸이 모두 같은 값으로 채워진다 | 자동 |
| M1-D4 | 셀 ⌘X | 원본이 바로 비워진다. 다른 곳에 ⌘V하면 값이 들어온다 | 자동 |
| M1-D5 | 시트 오른쪽 아래 끝(Z100) 근처에 큰 범위 붙여넣기 | 시트 안쪽만 채워지고 오류가 없다 | 단위 테스트 + 수동 |
| M1-D6 | 이 시트에서 범위 ⌘C → 엑셀 또는 구글 시트에 붙여넣기 | 같은 모양의 표로 들어간다 (구글 시트는 서식도) | 수동 전용 |
| M1-D7 | 엑셀 또는 구글 시트에서 범위 복사 → 이 시트에 ⌘V | 같은 모양으로 들어온다. 구글 시트의 굵게는 유지된다 | 수동 전용 |
| M1-D8 | 메모장·웹 페이지의 일반 글 복사 → ⌘V | 한 셀에 글이 들어온다 (줄바꿈이 있으면 여러 행) | 수동 전용 |
| M1-D9 | 셀 편집 중(F2) 글자 일부 선택 → ⌘C → 다른 셀 편집 중 ⌘V | 셀 복사가 아니라 글자 복사·붙여넣기로 동작한다 | 수동 전용 |

## M1-G 한글 입력 (실제 입력기)

자동 테스트는 입력기 조합을 흉내 낸 것이다. 실제 macOS·Windows 한글 입력기에서 확인한다.

| ID | 단계 | 기대 결과 | 구분 |
| --- | --- | --- | --- |
| M1-G1 | 셀 선택 → 한글 입력기로 `한글` 입력 → Enter | 첫 글자 `ㅎ`이 사라지지 않고 `한글`이 들어간다 | 수동 전용 |
| M1-G2 | 조합 중(`하` 상태)에 Enter | 조합만 끝나거나 바로 확정되어 아래로 이동한다. 같은 셀에 두 번 쓰이거나 두 칸 내려가지 않는다 | 수동 전용 |
| M1-G3 | 조합 중 Tab / 방향키 | 글자가 깨지거나 사라지지 않는다 | 수동 전용 |
| M1-G4 | 값 편집줄에서 한글 입력 → Enter | 셀에 `한글`, 한 칸만 아래로 이동 | 수동 전용 |

| ID | 단계 | 기대 결과 | 구분 |

## 결과 기록

`README.md` 수동 매트릭스에 `ID 범위 | 브라우저 | 날짜 | 결과`를 남긴다. 실패는 재현 단계를 적고, 가능하면 core 단위 테스트로 먼저 고정한 뒤 고친다 (`.codex/skills/test-policy/SKILL.md`).
