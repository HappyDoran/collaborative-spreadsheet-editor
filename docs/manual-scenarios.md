# 수동 확인 시나리오

사람이 브라우저에서 직접 확인하는 절차의 정본이다. 결과(브라우저 × 날짜 × 통과 여부)는 `README.md` 수동 매트릭스에 시나리오 ID로 기록한다. ID는 `단계-영역번호`(예: `M1-D3`) — 요구사항 번호(`docs/spec/requirements.md`의 E·C·A)와 구분하려고 단계 접두를 붙인다. 기능이 바뀌면 같은 커밋에서 이 문서를 갱신한다. 검증 계층에서의 위치는 `.codex/skills/test-policy/SKILL.md`.

- **자동**: `pnpm e2e`(`apps/web/e2e/`, Chromium)가 같은 ID로 돌리는 항목. 사람은 Safari와 실제 입력기에서만 다시 본다.
- **수동 전용**: 자동화로 재현할 수 없거나(실제 IME, 외부 앱 클립보드) 사람의 판단이 필요한(보기·느낌) 항목.
- 단축키는 Mac 기준(⌘)이다. Windows·Linux에서는 Ctrl로 같은 결과가 나와야 한다.

## 공통 준비

1. `pnpm dev` 실행 후 `http://localhost:3000`을 연다. 배포본을 확인할 때는 배포 주소를 연다.
2. 깨끗한 상태에서 시작하려면 시트 전체를 선택(⌘A)하고 Delete를 누른다. 저장소까지 비우려면 개발자 도구 → Application → IndexedDB → `sheet:default`를 삭제하고 새로고침한다.
3. 각 시나리오는 앞 시나리오와 독립이다. 필요한 값은 시나리오 안에서 만든다.

## 직접 재확인 실행 순서

`localhost:3001`에서 Safari와 Chrome을 각각 확인한다. 아래의 셀은 테스트용 예시다. 이미 값이 있으면 같은 크기의 빈 구역을 골라 기존 데이터를 보존한다. 각 항목은 직전 항목의 결과에 의존하지 않도록 필요한 값을 새로 만든다. F2가 macOS 기능 키에 묶여 있으면 Fn+F2를 누른다. 각 단계가 끝날 때 `README.md` 수동 매트릭스에 브라우저별 통과·실패와 실제 결과를 기록한다.

1. **M1-A4 — F2로 뒤에 붙이기:** 빈 셀에 `hello`를 확정하고 다시 선택한다. F2 → `!` → Enter를 누른다. 값이 `hello!`인지 확인한다.
2. **M1-A5 — 더블클릭 커서:** 다른 빈 셀에 `abcd`를 확정한다. 더블클릭한 뒤 `b`와 `c` 사이를 클릭하고 `X`를 입력해 Enter로 확정한다. 값이 `abXcd`인지 확인한다.
3. **M1-A8 — 편집 중 방향키:** `abcd`가 있는 셀을 선택해 F2를 누른다. ←와 →를 눌러 커서가 글자 사이에서 움직이고 이름 상자의 셀 주소가 바뀌지 않는지 확인한 뒤 Esc로 끝낸다.
4. **M1-B2 — 드래그 선택:** A3에서 C5까지 마우스로 드래그한다. 이름 상자가 `A3:C5`이고 A~C 열·3~5행 머리글이 강조되는지 확인한다.
5. **M1-D5 — 끝 경계 붙여넣기:** 빈 3×3 범위에 서로 다른 값 9개를 넣고 복사한다. Y99를 선택해 붙여넣는다. Y99:Z100 네 칸에만 원본의 왼쪽 위 2×2 값이 들어가고 오류가 없는지 확인한다. 대상 네 칸이 비어 있는지 먼저 본다.
6. **M1-D6 — 외부 앱으로 복사:** 이 시트의 빈 2×2 범위에 서로 다른 값 4개를 넣고 한 셀을 굵게 만든다. 범위를 복사해 Excel 또는 Google Sheets의 빈 영역에 붙여넣는다. 행·열 위치와 값이 같고, Google Sheets에서는 굵게도 유지되는지 확인한다.
7. **M1-D7 — 외부 앱에서 복사:** Excel 또는 Google Sheets에서 서로 다른 값 4개의 2×2 범위를 만들고, Google Sheets를 쓰면 한 셀을 굵게 만든다. 복사해 이 시트의 빈 셀에 붙여넣는다. 2×2 모양과 값, Google Sheets의 굵게가 유지되는지 확인한다.
8. **M1-D8 — 일반 글 붙여넣기:** 메모장이나 웹 페이지에서 `첫째` 한 줄을 복사해 빈 셀에 붙여넣는다. 한 셀에 들어가는지 확인한다. 이어 `첫째`와 `둘째`를 줄바꿈으로 나눈 두 줄을 복사해 다른 빈 셀에 붙여넣고, 두 행에 들어가는지 확인한다.
9. **M1-D9 — 편집 중 글자 복사:** 빈 셀에 `abcd`를 확정하고 F2로 편집한다. `bc` 글자만 선택해 ⌘C를 누른다. 다른 빈 셀에서 F2 → ⌘V → Enter를 누른다. 두 번째 셀에 `bc`만 들어가고 첫 셀은 `abcd`인지 확인한다.
10. **M1-E6 — 편집 글자 실행 취소:** 빈 셀에 `ab`를 확정한 뒤 F2로 편집하며 `c`를 덧붙인다. ⌘Z를 한 번 눌러 입력칸이 `ab`로 돌아가는지 확인한다. Enter 후에도 셀 값 `ab`가 남아 있어야 한다.
11. **M1-H3 — 툴팁:** B·I·U 버튼에 마우스를 차례로 올린다. 각 기능 이름과 Mac용 ⌘ 단축키가 보이는지 확인한다.
12. **M1-H4 — 좁은 창:** 브라우저 창 너비를 줄인다. 가로 스크롤로 오른쪽 열을 볼 수 있고 툴바·상태 표시줄이 겹치거나 잘리지 않는지 확인한 뒤 창 크기를 되돌린다.

Chrome에서는 영문 입력기를 선택한 뒤 다음 항목을 추가로 확인한다.

13. **M1-A1 — 첫 영문 입력:** A1을 클릭해 `hello` → Enter를 누른다. A1이 `hello`, 선택이 A2이고 상태가 입력 중 `입력`에서 확정 후 `준비`로 바뀌는지 확인한다.
14. **M1-A6 — 입력 취소:** 빈 셀에 `hello`를 확정하고 다시 선택한다. `bye`를 바로 입력한 뒤 Esc를 누른다. 원래 값 `hello`와 `준비` 상태가 유지되는지 확인한다.
15. **M1-A9 — Backspace 교체:** 빈 셀에 `hello`를 확정하고 다시 선택한다. Backspace → `new` → Enter를 누른다. 값이 `new`인지 확인한다.
16. **M1-A10 — 숫자·문자 정렬:** 빈 같은 행의 연속된 네 셀에 `1,234`, `-5.5`, `12%`, `abc`를 각각 확정한다. 앞의 세 값이 오른쪽, `abc`가 왼쪽에 붙는지 확인한다.
17. **M1-A13 — 끝까지 이동:** A1을 선택하고 →를 Z1까지, ↓를 Z100까지 계속 누른다. 이름 상자가 `Z100`이고 선택 테두리가 고정 머리글 아래에 숨지 않는지 확인한다.

**M1-C3**은 브라우저 수동 항목이 아니다. `pnpm test`에서 `packages/sheet-core/src/sheet.test.ts`의 혼합 서식 토글 사례가 통과하는지 확인한다.
